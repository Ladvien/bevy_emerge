# 2026-10-30 relations: `relations_solve` mends a map's broken relations with one undo

## Summary
`relations::solve` (slice 3) is now a registered operation, `relations_solve`, reachable over generic apply and from the Terrain field line `relations solve`. It solves the open map against `<map>.relations.ron`, writes the moved rows (riders too) as a `RowDelta`, and one undo puts every row back at its index. `RowDelta::apply` now lets a delta re-add an id it also removes.
