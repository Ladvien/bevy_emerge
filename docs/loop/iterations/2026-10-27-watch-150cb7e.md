## Summary

`watch::adopt` re-read a kit's `library.ron` by replacing the whole `Project` with a fresh
`Project::open`. That is a change to the editor's *memory*: the placed pieces were spawned from the
library the editor held when it opened, and the systems that redraw them are driven by
`Project::touched`, which only `tiles::commit_measured` ever filled. So a person editing a piece's
`stretch_y`, `scale`, `extent` or `mesh` in a text editor got the palette and the inspector updated
and the world unchanged. E-007's shape, one file over.

The re-read now fills `touched` with `tiles::changed_ids` — the same comparison the Tiles tab uses,
made `pub(crate)` so there is one answer to "what did the library change" rather than two — and it
carries `open_map_name` across the swap, which `Project::open` starts at `None`.

No enhancement shipped: 25 of the 45 minutes went on a cold test build (13 m 28 s for the first
one), and the gate plus a report is the honest use of what was left.

## Review

Reviewer **could not run** — no subagent was spawned this pass (cloud 429s have taken it five passes
running). The five questions, answered by me:

1. **Does the fix address the reported defect, not a symptom?** Yes — `touched` is the mechanism the
   redraw already reads; the watcher was simply the one library door that did not write it. Suppressing
   the drift was not an option: the library is right and the picture was wrong.
2. **Is there a second answer to the same question?** `changed_ids` was duplicated for exactly one
   commit; it is now `pub(crate)` and both doors call it. A second copy in `watch` was rejected.
3. **Can the new test pass for the wrong reason?** No — it asserts the project adopted the edit
   (`adopted`) *and* then asserts the screen, so an editor that ignored the file fails rather than
   passes.
4. **Does the change break the editor's own writes?** The editor's own `library.ron` write arrives as
   a stamp change and is filtered by `differs` before `adopt` runs, so `touched` cannot be filled
   from the editor's own save.
5. **What did the fix not cover?** A vocabulary reload (`reload_vocab`) still does not redraw — but a
   token edit resizes nothing, so there is nothing on screen to redraw. The real remaining cost is
   E-003: the whole project, every GLB re-measured, per save.
