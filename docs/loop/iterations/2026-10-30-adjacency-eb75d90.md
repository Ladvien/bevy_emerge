# 2026-10-30 adjacency: a kit says whether it can loop a hallway back (#160)

Focus: kit stress tests (lens #4) · Commits: eb75d90 · Machine: big · Outcome: shipped

## Summary
`adjacency::ring(library, divisions)` builds the smallest closed loop a kit can make: four pieces of one turned footprint around a point, each at a quarter turn, every inner seam declared and passing `faults`. Returns the pieces and the four-piece map, or `None`. Complements `dead_ends` (#142), which cannot see a kit that never turns.
