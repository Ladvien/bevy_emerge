## Bugs fixed
### #158: a project file created while the editor is open is never read
Must-fix: blocks y (the documented live reload of an optional file does not happen on its first write), common y (optional files are created, not edited, first), no workaround n (restart, or write twice).
Root cause: `tick_watch` skipped `previous.is_none()`. Fix: `Watched::absent` remembers watched paths with no file at the last tick; one that now has a file is a change. Project switch clears it; the editor's own first save of a map still passes through `adopt_changes`' content comparison.
Regression check: `a_project_file_created_while_open_is_read::a_repetition_file_created_after_the_open_reaches_the_repeats_row` passes after. Before: reproduced live on the a5e14bb editor (REPEATS frames 0–80 of the first take stayed `chair ×4, 1 more` after the file was created at 4.4 s); the cargo run itself compiled after the fix was written, so it is not a failing-before observation.
