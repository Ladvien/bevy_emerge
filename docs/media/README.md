# `docs/media/`: every image, with the command that made it

The README's and the guide's GIFs, recorded from the running editor by a storyboard through the MCP server and rendered by `tools/demo/render.py` ([`tools/demo/README.md`](../../tools/demo/README.md) has the setup: start the editor with `BEVY_BRP_PORT=15710`, set `BEVY_GRIMOIRE_MCP`). Changelog clips live in `docs/changelog/media/`, in Git LFS, and are listed by `CHANGELOG.md`. The 64-second demo video moved to the book on 2026-10-31 (`bevy-coven.github.io/src/media/bevy_grimoire-demo.mp4`), because videos live only there.
